# Update Cloudflare

A utility for updating Cloudflare DNS records.

## Installation

```bash
pip install -e .
```

## Usage

```bash
python -m update-cloudflare -i eth0
#or
update-cloudflare -i eth0
```

## Features

- Update DNS records automatically
- Support for multiple record types
- Error handling and logging

## Requirements

- Cloudflare API access
